# ソードワン 自動化マニュアル

山口が作った自動化の仕組みを、社内のみんなが見られるようにまとめたサイトです。
GitHub Pages で公開しています。

## 構成

- `index.html` … 一覧(トップページ)
- `hajimeni.html` … AI初心者向けの「はじめに読むページ」
- `pages/` … 仕組みごとのマニュアル
- `assets/style.css` … 共通デザイン
- `build.py` … `pages/` と `index.html` を作るスクリプト

## マニュアルを足す・直すとき

Claude に「自動化マニュアルに○○の仕組みを追加して」と頼めばOKです。
自分で直す場合は `build.py` の `PAGES` を編集して `python build.py` を実行し、GitHub に上げます。
(`pages/line-shukkin.html` と `hajimeni.html` は手書きのページです)

## 注意:公開サイトです

URL を知っていれば社外の人も見られます。次のことは書かないでください。

- お客様・応募者の情報
- 社外の方のお名前、メールアドレス、電話番号
- 管理表などの URL・ID、パスワード、ログイン方法
- 単価・金額・売上の数字
