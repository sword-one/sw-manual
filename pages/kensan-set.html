検算セット ― AIが作ったものを、正解例と決まった計算で確かめる

Claudeが仕事の最後に使う山口PCが必要

AIが作った見積書や集計は、いつもは合っていても、たまにまちがえることがあります。検算セットは、決まった計算(数量×単価=金額、合計、消費税、日数)と、過去の正解例を使って、まちがいを自動で見つけます。

1何が変わった?

これまで

AIの出力を人が目で見て確かめていました。毎月同じ形なので、見落としやすい作業でした。

→
いま

見積書・売上集計・甚目寺の転記のあと、Claudeが検算をして「ALL_OK」か「NG(どこがいくら違うか)」を報告します。NGなら、納品・転記・入力の前に止まります。

2いつ動く?

見積書を作ったあと納品の前に。
売上を集計したあと着地見込みシートに入れる前に。
甚目寺のシフトを転記・手配したあと自動実行のときも同じです。

3全体の流れ

  1. Claude
    いつもの仕事(見積書・集計・転記)をする
  2. Claude
    決まった計算で確かめる見積書：数量×単価=金額、明細の合計=小計、消費税=小計×10%、合計、品名の月。売上：単価×日数=小計、見積書との突き合わせ。転記：出勤日とコマ数。
  3. Claude
    過去の正解例と比べる見積書は前月の正解例と単価を比べ、変わっていれば「要確認」。売上と転記は、正解例をもう一度計算して同じ結果が出るか(やり方が壊れていないか)を確かめます。
  4. Claude
    ALL_OK / NG / 要確認 で報告NGなら止めます。
  5. 人
    要確認・NGが出たら中身を見る単価の改定など、正しい変更のこともあります。

4Claudeへの頼み方と、人がやること

こう話しかける
11月の見積書作って(最後に検算まで)
見積書の検算して
11月のヘルパー売上集計して
人がやること
  • NG・要確認が出たら中身を見て判断する
  • 正解例にしてよい月は、Claudeに「この月を正解例にして」と伝える

5使っている道具

Excel・PDF(見積書)Dropboxの見積書フォルダのファイルを読むだけです。
検算のプログラムデスクトップの mail-tool の中の kensan フォルダにあります。

6気をつけてほしいこと

読むだけです

金額欄やファイルは書き換えません。

正解例は確認済みの月だけ

まちがった月を正解例にすると、翌月の比較もずれます。
