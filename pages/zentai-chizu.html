全体の地図 ― 自動の仕組みは、3つの置き場所で動いている

見るためのページまとめ

仕組みが増えると「どこで動いているのか」がわからなくなります。置き場所は3つあり、それぞれ動く条件がちがいます。止まったときに、どこを見ればいいかもまとめました。

1何が変わった?

これまで

定期タスクを探しても見つからない、止まっていることに気づかない、ということがありました。クラウドのタスクとPCのタスクは、見る画面がちがいます。

→
いま

この地図を見れば、どの仕組みがどこにあって、どう止めるかがわかります。止まっていないかは、実行台帳が毎日確かめます。

2いつ動く?

迷ったとき「あの仕組み、どこで動いてたっけ」と思ったときに見ます。

3全体の流れ

  1. クラウド
    claude.ai の「スケジュール済みタスク」PCが閉じていても動きます。画面上の「非表示のタスク…表示」を押すと、プロジェクトの中で作ったタスクも出ます。「このコンピュータで実行」と書かれたものは、山口PCとChromeが必要です。
  2. PCのアプリ
    Claudeデスクトップアプリ → Code → 左の「Scheduled」アプリが開いているときに動きます。閉じていたら、次に開いたときに1回だけ動きます。前の回が確認待ちで止まったまま残っていると、次の回が始まりません。
  3. PCの見張り役
    Windowsの「タスク スケジューラ」PCが起動してログオンしていれば動きます。

9こんなときは

定期タスクが減ったように見える

クラウドの画面とPCのアプリの画面は別です。クラウドの画面では「非表示のタスク…表示」を押すと全部出ます。

PCのタスクが動いていない

アプリでその回を開き、確認が出ていれば許可、止まったまま残っていれば停止します。
